# Deployment

## Clone Repository

```bash
git clone https://github.com/praveen7500/enterprise-etl-pipeline-airflow-snowflake-dbt.git
```

## Install

```bash
pip install -r requirements.txt
```

## Start Docker

```bash
docker compose up
```

## Run dbt

```bash
dbt run
```

## Start Airflow

```bash
airflow scheduler
```
